## Workarounds (see BUILD_REPORT.md for WHY / UPSTREAM / WHEN REMOVABLE)

1. **gateway-crds-helm Secret too large** → `helm template \| kubectl apply --server-side`
2. **SR chart 0.3.0 dashboard selectorLabels** → patch Deployment+Service with `token-factory.amd.com/role=router` in `install-semantic-router.sh`
3. **AIGW modelNameOverride + dual extproc** → `lora_name` set to real model IDs (`openai/gpt-oss-120b`, `openai/gpt-oss-20b`)
4. **kind LoadBalancer pending** → EnvoyProxy `ClusterIP` in compiler manifests
5. **No SSH to MI300X** → public HTTP endpoint inventory only

## Fallback (partial)

- Policy compiler emits multi `backendRefs` with priority 0/1 on AIGatewayRoute rules.
- `BackendTrafficPolicy` health checks on `/v1/models` + retry now generated by compiler.
- Deliberate primary backend break (IP → 127.0.0.1) returned **HTTP 500** — automatic failover on AIGW priority path **not fully proven** (V2).
